# 1. Архитектура компьютерных систем. Архитектура Фон-Неймана и Гарвардская архитектура. Принципы архитектуры Фон-Неймана. Архитектуры NUMA и UMA.

Гарвардская архитектура VS Фон-Нейманская архитектура

(про разделение памяти по смыслу)

Фон-Неймановская архитектура

- Одна общая память (адресное пространство) для команд и данных.
- Процессор читает инструкции и данные через общую шину доступа к памяти -> возможное узкое место фон Неймана.

Гарвардская архитектура

- Раздельная память для команд и для данных (часто и раздельные каналы/шины).
- Можно параллельно читать инструкцию и работать с данными -> меньше конфликтов доступа, часто в микроконтроллерах/DSP.

UMA VS NUMA

(про многопроцессорность и расстояние до RAM)

UMA (Uniform Memory Access)

- Архитектура многопроцессорной системы, где есть общая оперативная память, и для всех CPU время доступа к ней примерно
  одинаковое.
- Простая модель для ОС, но общий интерконнект/шина/контроллер памяти может стать узким местом при росте числа
  процессоров.

NUMA (Non-Uniform Memory Access)

- Архитектура многопроцессорной системы, где память распределена по узлам: у каждого CPU/сокета есть локальная RAM, а
  доступ к удалённой памяти других узлов медленнее.
- Лучше масштабируется по CPU и памяти, но ОС должна быть NUMA-aware (учёт локальности: размещение памяти,
  affinity/планирование).
