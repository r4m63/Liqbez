Jakarta EE

JCP - издает стандарты java, стандарты java, изменения в jvm и тд. Можно зарегистрировался самому и принимать участие
в голосовании. Самая натуральная Демократия. Благодаря JCP есть обратная совместимость, тк компании с деньгами не
готовы вкладывать в эксперименты (как .NET), у java все прямо, все тщательно обсуждается и вылизывается. Пока медленная
демократия java и jcp чухалась, spring обогнал.

Spring на основе POJO строит архитектуру всю. За счет того что они бежали быстрее за рынком, то их фреймворки разбухали.
В то время когда стандартные фреймворки java EE, они все упрощали. И сейчас вышло так что Spring фреймворки сложнее
стандартных. Но об этом забыли тк рынок вытоптан Спрингом.
Дело дошло до того что Oracle (они владельцы java и после решения JCP, они занимаются выпуском стандартов), они отказались
от выпуска стандартов Java EE, они не захотели вести стандарты (документацию )и отдали их в руки комьюнити JCP
(по факту не отказались, тк как у них самих есть 2 веб сервера WebLogic и GlassFish). Теперь это официально открытая
лицензия от комьюнити, и переименовались в Jakarta EE, тк торговая марка Java EE принадлежит Oracle.

Jakarta стек подходит идеально под монолитные, Spring стек идеально подходит под микросервисы.

Более того очень много аутсорсинговых проектах где крутятся самые большие деньги -- на JavaEE
